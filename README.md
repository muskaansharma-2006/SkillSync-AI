# SkillSync AI

> **Don't prove what you learned. Demonstrate what you can do.**

SkillSync AI is an AI-powered competency assessment platform designed to evaluate a candidate's **practical skills and problem-solving ability**, rather than relying only on certificates, degrees, or traditional MCQ-based assessments.

The platform helps candidates understand their competency level and skill gaps, while giving recruiters a structured way to evaluate candidates based on demonstrated abilities.

## 🚀 Key Features

### 👨‍🎓 Candidate
- Candidate onboarding and profile
- Skill selection
- Pre-assessment before starting
- Practical skill assessments
- Competency evaluation
- Skill-gap identification
- Recommended practice areas
- Competency Profile / Competency Passport
- Assessment history

### 🏢 Recruiter
- Recruiter dashboard
- Define required competencies for a role
- View candidate profiles
- Evaluate candidate competency
- Job-fit assessment
- Proof of demonstrated skills

### 🤖 AI Features
- AI-assisted competency evaluation
- Intelligent skill-gap analysis
- Personalized practice recommendations
- AI-powered candidate assessment
